# 造梦终端 · 破妄法门

终端挂机 RPG。花果山篇，18 个阶段、6 个副本。

## 安装

```bash
curl -fsSL https://raw.githubusercontent.com/你的用户名/zdzm/main/install.sh | bash
```

或手动：

```bash
pipx install git+https://github.com/你的用户名/zdzm.git
```

## 使用

```bash
zdzm
```

存档在 `~/.zdzm/`，纯本地，不联网。

## 命令

```
status       角色面板
push         自动推图
farm 1-1     循环刷副本
enter        选副本进入
skills       技能加点（方向键）
loadout      技能装配
collect      收集进度
quit         存档退出
```
